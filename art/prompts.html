HEXARIA — Atelier d'images

Tous les prompts pour générer, avec votre propre IA d'images, les personnages, monstres, bâtiments, éléments de décor, textures, fonds d'arène et illustrations du jeu. Chaque fiche donne le prompt prêt à coller, le format, la taille conseillée et le nom de fichier exact attendu par le jeu. 25 image(s) sur 72 sont déjà intégrées.

1Copier un prompt avec le bouton doré, puis le coller dans votre IA (Midjourney, GPT Image, Flux, Gemini…).
2Garder le même style : générez une première image qui vous plaît et fournissez-la comme image de référence de style pour toutes les suivantes.
3Enregistrer l'image sous le nom de fichier indiqué dans le dossier art/raw/ (ou la déposer sur la fiche si npm run dev tourne).
4Intégrer : lancez npm run art. Le fond blanc est retiré, les planches sont découpées et converties ; rechargez le jeu, c'est utilisé automatiquement.
Conseils pour de meilleurs résultats
  • Fond blanc pur pour les personnages, monstres, bâtiments et décors (pas d'ombre au sol, pas de dégradé) : c'est ce qui permet le détourage automatique. Les textures, fonds d'arène, événements et écran titre sont au contraire des images pleines.
  • Vue isométrique de trois quarts, personnages tournés vers la droite : le jeu retourne l'image quand il faut les faire regarder à gauche.
  • Les planches (3 formes d'évolution, ou plusieurs objets de décor) doivent avoir de larges espaces blancs entre les éléments, sinon la découpe automatique les fusionnera. Si votre IA n'y arrive pas, utilisez les variantes « une forme à la fois » des créatures, ou découpez les planches de décor vous-même.
  • Pour les créatures, gardez les mêmes couleurs et la même identité entre les trois formes ; la forme 3 doit être nettement plus grande.
  • Les images restent originales : ne demandez pas de personnages de licences existantes.
  • Une image ratée ? Régénérez uniquement celle-là et écrasez le fichier, puis relancez npm run art ; rien d'autre n'est touché.
Bloc de style commun (déjà inclus dans chaque prompt) : Hand-painted 2D video-game illustration in the style of Hades and Bastion (Supergiant Games): bold dark ink outlines, painterly cel shading with visible brush texture, rich saturated jewel colors, warm amber rim light against cool teal shadows. Original design, dark-fantasy mood with glowing bioluminescent accents.
Fond : Plain pure white background (#FFFFFF), no ground, no ground line, no floor line, no horizon line, no cast shadow, no text, no labels, no watermark, no UI.
Mode développement détecté. Déposez vos images (une ou plusieurs, nommées comme indiqué) ici ou sur une fiche : elles sont enregistrées, détourées et intégrées au jeu automatiquement.
