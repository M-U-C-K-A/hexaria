# Génération des images

Tout est dans **`art/prompts.html`** (généré par `npm run art:page` depuis `scripts/art/promptData.ts`).

- Ouvrir la page, copier un prompt, générer l'image avec votre IA, l'enregistrer sous le nom indiqué dans `art/raw/`.
- `npm run art` détoure, découpe, convertit et met la page à jour.
- Avec `npm run dev`, les images peuvent aussi être déposées directement sur les fiches de la page.
